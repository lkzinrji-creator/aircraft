# Aircraft Mod — Minecraft Java 26.3

Um avião funcional para Minecraft Java 26.3 + Fabric.

## Visual

- Modelo 3D do avião feito com várias partes voxel.
- Pintura branca/prata com faixas vermelhas, cockpit azul, hélice preta e pontas amarelas.
- Trem de pouso e rodas incluídos.
- Hélice com quatro pás que gira separadamente do corpo.
- Texturas PNG incluídas para o avião e para os itens.

## Gameplay

- ⛽ Combustível de 0 a 2400.
- 🛢️ Gasolina abastece +600.
- 🌀 Hélice gira devagar com o motor desligado e rápido com combustível.
- 🚀 Sprint = turbo.
- 🐌 Shift = desaceleração.
- 🎯 O avião voa na direção da câmera.
- 💾 Combustível é salvo junto com a entidade.

## Build

O projeto segue a estrutura Fabric 26.3 e usa Java 25 no CI. O GitHub Actions compila o projeto e publica o JAR como artifact.
